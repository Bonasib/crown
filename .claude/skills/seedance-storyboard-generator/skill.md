# 技能：Seedance 2.0 视频脚本与分镜生成器

## 技能说明

本技能帮助用户将故事创意转化为完整的视频制作文件包，包含：
1. 完整剧本（按集/场景结构化）
2. 分镜脚本（每个镜头的 Seedance 2.0 结构化提示词）
3. 素材清单（角色、场景、道具的生成提示词）

## 调用方式

```
/seedance-storyboard-generator [故事标题或创意简述]
```

---

## 执行流程

### 第一步：需求确认

收到用户输入后，询问或确认以下信息：

| 参数 | 说明 | 示例 |
|------|------|------|
| **故事来源** | 原创 / 改编自已有作品 | 改编自《水浒传》 |
| **目标时长** | 每集分钟数 / 总集数 | 每集 3 分钟，共 6 集 |
| **风格基调** | 写实 / 古风 / 现代 / 动漫 | 写实古装，北宋风格 |
| **主要角色** | 核心人物列表 | 林冲、陆谦、高衙内 |
| **核心冲突** | 故事主线张力 | 忠义与迫害，家破人亡 |

### 第二步：生成剧本

输出格式：

```markdown
# [故事名称] 剧本

## 故事概要
[200 字以内的故事梗概]

## 人物表
| 人物 | 身份 | 性格特征 | 外貌描述 |
|------|------|----------|----------|

## 第X集：[集名]

### 场景 X-1：[场景名称]
**地点：** [具体地点]
**时间：** [时间段]
**情绪基调：** [紧张/温情/悲壮/...]

**动作描述：**
[人物行为和场景描述，200-400字]

**对话：**
[角色名]：「[台词]」
[角色名]：「[台词]」

**场景情绪：** [递进/转折/高潮/...]
```

### 第三步：生成分镜脚本

对每个场景拆分为 4-8 个镜头，每个镜头生成 Seedance 2.0 结构化提示词：

```markdown
## 第X集 E0X 分镜脚本

### 镜头 X-1-A：[镜头功能描述]

**画面内容（Subject）：**
[主体描述]

**镜头语言（Camera）：**
- 景别：[远景/全景/中景/近景/特写]
- 运动：[固定/推/拉/摇/跟/环绕]
- 角度：[平视/仰视/俯视/斜角]

**Seedance 提示词：**
```
[英文结构化提示词，参见 structured-prompt.md 格式]
```

**时长建议：** [3-8] 秒
**转场方式：** [切/叠化/淡入淡出]
```

### 第四步：生成素材清单

为每个项目生成角色、场景、道具的 Seedance 参考图生成提示词：

```markdown
## 素材生成清单

### 角色参考图

#### [角色名]
- **用途：** Seedance ControlNet 参考
- **提示词：**
  ```
  [角色外貌的英文描述提示词]
  ```

### 场景参考图

#### [场景名]
- **用途：** 背景 / 环境参考
- **提示词：**
  ```
  [场景描述的英文提示词]
  ```
```

## Seedance 2.0 提示词规范（快速参考）

### 结构模板

```
[主体描述], [动作/状态], [环境/背景], [光线], [镜头语言], [风格/氛围], [技术参数]
```

### 关键参数词汇

**景别**
- `extreme wide shot (EWS)` — 大远景
- `wide shot (WS)` — 远景
- `medium shot (MS)` — 中景
- `close-up (CU)` — 近景
- `extreme close-up (ECU)` — 特写

**镜头运动**
- `static shot` — 固定镜头
- `slow push in` — 缓慢推进
- `pull back` — 拉远
- `pan left/right` — 左右摇镜
- `tracking shot` — 跟拍
- `crane shot` — 升降镜头
- `orbit/arc shot` — 环绕镜头
- `handheld` — 手持晃动

**光线**
- `golden hour lighting` — 黄金时段光
- `overcast diffused light` — 阴天漫射光
- `dramatic side lighting` — 戏剧性侧光
- `moonlight, cold blue tones` — 月光冷调
- `firelight, warm flickering` — 火光摇曳

**风格**
- `cinematic, film grain` — 电影质感
- `ancient Chinese aesthetic` — 中国古典美学
- `ink wash painting style` — 水墨风格
- `hyper-realistic` — 超写实

### 负面提示词（Negative Prompt）常用词

```
low quality, blurry, distorted faces, extra limbs, watermark, text overlay, 
modern elements, anachronistic objects, oversaturated colors
```

---

## 质量检查清单

生成完成后，对照以下标准检查：

- [ ] 每集分镜数量在 20-40 个镜头之间
- [ ] 每个提示词包含主体、环境、光线、镜头运动四个核心要素
- [ ] 角色外貌描述在全文一致（参考素材清单）
- [ ] 场景地点在同集内保持连续性
- [ ] 情绪节奏有张弛（每集至少一个高潮镜头）
- [ ] 提示词为英文，避免中英混用

Add a new shared TypeScript type or enum to `packages/types` and update all apps that need it.

## Steps

1. Ask the user for:
   - Type/enum name (PascalCase)
   - Whether it is a type alias, interface, or enum
   - The fields or members it should have
   - Which apps or packages will consume it

2. Open `packages/types/src/index.ts` (or the relevant domain file if one exists) and add the new type following existing conventions:
   - Enums use UPPER_SNAKE_CASE members
   - Monetary fields end in `Minor` and are `number` (integer)
   - Dates are `Date` or ISO string — pick the pattern already used in that file
   - Export the type from the package's barrel

3. If the type mirrors a Prisma model, check `packages/db/prisma/schema.prisma` to ensure naming stays consistent.

4. Show the import statement consumers should use:
   ```ts
   import type { MyNewType } from '@ronda/types';
   ```

5. List every file that was created or modified.

## Project context

- `packages/types` is a shared package imported as `@ronda/types`
- Do not duplicate types already generated by Prisma — import from `@ronda/db` instead
- ADR-003: all money is stored/passed as minor units (integers), never floats

# 视频剧本与分镜工作流

## 概述

本项目使用**即梦 Seedance 2.0**平台将文学故事转化为 AI 生成视频。工作流分为剧本创作、分镜设计、素材生成三个核心阶段。

---

## 文件体系

每个项目（如"林冲项目"）包含以下标准文件：

```
[项目名]/
├── [故事名]_剧本.md        ← 完整剧本，按集/场景结构化
├── [故事名]_素材清单.md    ← 角色/场景参考图生成提示词
├── [故事名]_E01_分镜.md   ← 第1集分镜脚本（含Seedance提示词）
├── [故事名]_E02_分镜.md   ← 第2集分镜脚本
└── 使用指南.md             ← 项目专属操作说明
```

## 剧本格式规范

### 文件头部

```markdown
# [故事名] 剧本

**改编自：** [原作品] / 原创
**作者：** [原著] / 剧本改编：[改编者]
**总集数：** X 集
**单集时长：** 约 X 分钟
**风格基调：** [如：写实古装，北宋背景，悲剧基调]

---

## 故事概要
[200字以内，含核心冲突与主题]

## 人物表
| 人物 | 身份 | 性格 | 外貌（用于素材生成） |
```

### 场景块格式

```markdown
## 第X集：[集名]

### 场景 X-Y：[场景标题]

- **地点：** [具体地点]
- **时间：** [白天/黄昏/深夜/...]
- **天气：** [晴/雨/雪/风/...]
- **情绪基调：** [紧张/温情/悲壮/...]

**[动作描述]**
用第三人称现在时描述人物行为和场景变化。重点描述视觉元素（动作、表情、环境变化），而非内心独白。

**[对话]**
林冲：「[台词]」
陆谦：「[台词]」
```

## 质量标准

### 分镜质量指标

| 指标 | 标准 |
|------|------|
| 镜头数量（每集） | 20-40 个 |
| 提示词完整性 | 主体 + 环境 + 光线 + 镜头运动 四要素齐全 |
| 提示词语言 | 纯英文 |
| 角色描述一致性 | 每个角色使用统一的标准描述段落 |
| 情绪节奏 | 每集至少 1 个高潮镜头，张弛有度 |
| 场景连续性 | 同集内地点转换有过渡镜头 |

### 剧本质量指标

| 指标 | 标准 |
|------|------|
| 单集场景数 | 3-6 个场景 |
| 视觉化描写 | 80% 以上描述可直接转化为画面 |
| 对话密度 | 每场景对话不超过 5 轮（AI生成视频口型有限） |
| 情绪弧度 | 每集有明确的情绪起伏 |

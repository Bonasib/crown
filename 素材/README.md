# 素材目录

此目录存放各项目生成的视频片段和参考图。

## 建议子目录结构

```
素材/
├── 林冲项目/
│   ├── 角色/        ← 角色参考图 (.jpg/.png)
│   ├── 场景/        ← 场景参考图
│   ├── E01/         ← 第1集镜头视频 (.mp4)
│   ├── E02/
│   └── ...
├── 聂风项目/
└── 项链项目/
```

## 文件命名规范

| 类型 | 格式 | 示例 |
|------|------|------|
| 视频镜头 | `E[集号]_S[场景]_[镜头字母].mp4` | `E01_S02_A.mp4` |
| 角色参考图 | `[角色名]_ref_[版本号].jpg` | `林冲_ref_01.jpg` |
| 场景参考图 | `[场景名]_ref.jpg` | `山神庙夜_ref.jpg` |
